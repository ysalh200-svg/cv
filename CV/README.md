# CV with a REAL local CSS Framework

This project uses **Bootstrap v5.3.6 CSS**, saved inside `bootstrap/bootstrap.min.css` (not only a CDN link). Bootstrap is an actual installed CSS framework asset.

Open `index.html` in a browser, even without internet to see Bootstrap styling. The clock uses Fetch API (`worldtimeapi.org`) when internet is available.

### Framework elements used
- Responsive Bootstrap grid: `row`, `col-12`, `col-md-6`, `col-lg-6`
- Bootstrap UI: `navbar`, `card`, `btn`, `form-control`, `shadow-sm`
- Utilities: `p-3`, `rounded`, `d-flex`

Files: `index.html`, `style.css`, `script.js`, `bootstrap/bootstrap.min.css`. Upload all to GitHub keeping the `bootstrap` folder.
